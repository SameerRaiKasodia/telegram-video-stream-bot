# Telegram Video Streaming Bot

A Java-based Telegram bot developed using Maven and Telegram Bot API that processes uploaded video files and generates streaming/download links dynamically.

## Features
- Accepts video files from users
- Generates video streaming/download links
- Real-time interaction using long polling
- Command handling with Telegram Bot API

## Technologies Used
- Java
- Maven
- Telegram Bot API

## How to Run
1. Clone the repository
2. Add your Telegram bot token in the Main class
3. Run the application
